= 在NetApp Data Classification中自訂過期資料定義
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
NetApp Data Classification 可識別過時資料，協助您發現節省成本的機會並應對循規風險。您可以自訂過時資料的定義，使其符合組織的實際需求，並根據資料的最後存取時間或最後修改時間來識別過時資料。

可以根據資料的_最後存取時間_或_最後修改時間_來定義過時資料。您可以選擇六個月到十年的時間段。

預設情況下，如果資料上次修改時間距今已有三年，則該資料視為過期資料。

.定義過期數據
. 在資料分類中，選擇**配置**。
. 在 Configuration 頁面中，選取 **Settings** 標籤。
. 在過期資料定義標題下，選取 *Edit* 。
. 在 **File property** 下拉式功能表中，選擇是否要根據檔案的 *Last accessed* 或 *Last modified* 來定義過期資料。
. 選擇過期資料定義的時間段。
. 選擇**儲存**。
